الـ API للمطورين وأصحاب اللوحات

آخر تحديث: 16 أكتوبر 2026

الـ API بتاعنا متوافق مع النظام القياسي (API v2) اللي بتستخدمه كل لوحات الـ SMM — يعني تقدر تضيفنا كمزود في لوحتك في دقيقة.

البداية

  1. سجّل دخولك وافتح حسابي ← الـ API واعمل مفتاح.
  2. ضيف الرابط والمفتاح في لوحتك كمزود جديد (Provider).
  3. اشحن رصيدك — كل الطلبات بتتخصم من رصيد حسابك.

مثال PHP

$ch = curl_init('https://bqiryyoanqleobzlztbl.supabase.co/functions/v1/api');
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query([
  'key' => 'YOUR_API_KEY', 'action' => 'add',
  'service' => 1, 'link' => 'https://instagram.com/username', 'quantity' => 1000
]));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);
$result = json_decode(curl_exec($ch));

مثال cURL

curl -X POST https://bqiryyoanqleobzlztbl.supabase.co/functions/v1/api \
  -d key=YOUR_API_KEY -d action=balance

ملاحظات

  • الأسعار بالجنيه المصري لكل 1000 (والباقات Package سعر للباقة الواحدة).
  • الحد الأقصى 120 طلب في الدقيقة لكل مفتاح.
  • لو الطلب فشل عند التنفيذ، المبلغ بيرجع لرصيدك تلقائياً.
  • متشاركش مفتاحك مع حد — ولو اتسرب اعمل مفتاح جديد من حسابي والقديم هيتوقف فوراً.
